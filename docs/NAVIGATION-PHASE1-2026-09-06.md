# 官网导航第一阶段 · 本地实现与验收

日期：2026-09-06。基线：`327e1c0`。状态：代码、自动回归与最终浏览器点击复验完成，已获得用户上线授权；本文件记录发布候选版验收，最终部署状态以发布任务记录为准。

## 已实现

- 桌面统一原创豆豆标识、游戏 / 排行榜 / 玩法 / 关于 / 中文 / EN。英文采用 Play / Leaderboard / How to Play / About。
- 桌面复用原标语栏的网格行；手机以紧凑导航替换大标题区；短横屏利用左侧空白，不挤压棋盘。
- 原侧栏/浮动的站点级排行榜与玩法、关于按钮退出显示。开始卡片内的排行榜、玩法和画面与声音保留；排行榜全屏界面继续使用自己的返回、继续和语言控制，不叠加第二层导航。
- 当前游戏入口不会调用开始、重开或清空存档；游戏中打开菜单、玩法或排行榜先暂停，返回后不自动继续。
- 切换语言使用页面内确认框，默认焦点是“留在本局”。取消不修改语言偏好；确认才沿既有路径切换并保留挑战参数。旧浏览器有非原生 dialog 的退化处理。
- 菜单支持原生链接、Tab、Escape 和焦点返回；导航键盘事件不传给游戏快捷键。文档覆盖游戏时导航不可聚焦。
- 使用既有 HTML/CSS 和中英文同源构建。未引入依赖、账户、广告、支付、空链接、攻略正文或第三方资源。
