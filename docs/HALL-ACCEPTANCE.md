## 实际交付

- 常驻奖杯完整按钮：桌面右侧栏，手机顶部；开始键旁有同尺寸青紫按钮，金色仍留给开始。
- 开始页真实云榜预览，可一键进入全屏大厅；旧服务只回退展示已知公开最高纪录，绝不猜个人排名。
- 结算页固定操作栏并排展示“再来一局 / 查看全球排名”，不再被长战绩挤到下方。
- `/leaderboard/`、`/en/leaderboard/` 都有 GitHub Pages 可直接访问的静态入口，不依赖新窗口或 404 重写。
- 同文档站内路由：打开大厅暂停本局，关闭后仍为暂停；主按钮可以明确继续。浏览器后退/前进保留本局。
- 金银铜荣誉卡自然适配 0–3 人；并列按真实 rank 显示，不按数组位置强行称亚军。
- 按最佳单局展示完整分数、同局进度/连击/日期；个人真实排名、超过最近更高成绩所需分数、本人定位、附近列表、分页。
- 同分并列且跳号（1、1、3），差分严格 +1。榜首挑战自己的纪录。历史规则不显示跨版本追分目标。
- 服务端快照 revision 变化时重新加载，不能混拼新旧分页；加载、空榜、失败、接口未安装分别展示。
- 本机先自动保存；确认昵称后公开；允许只保存本机昵称。失败安全重试，不以 HTTP 200 代替 accepted:true。
- 本局/改名/新开局均有陈旧响应隔离。确认界面加载失败则禁止自动公开。
