## 变更

- 英文挑战栏使用 `DAILY`、`Lv. N`、`Unplayed`、`Best`，完整挑战和关卡名称保留在标题提示中。
- 每日挑战固定为四列；六个练习按钮及图鉴固定在同一行，不新增横向滚动。

## 验收结果

- 24 组几何检查通过：320、375、390、430、768、1440px 六种屏宽，各测中文满星千万分、英文满星千万分、英文最大安全整数成绩、英文只解锁两关。两栏子项在同一行、未出界，卡片及两栏横向溢出均为 0。
- 另测英文未挑战状态；375px 满星状态曾出现 4px 溢出，调整窄卡片间距后复测通过。
- 浏览器实点：图鉴打开/关闭正常、挑战进入第 5 关、练习进入第 3 关。
- 844 × 390 横屏保留原有精简模式（两栏隐藏），卡片横向溢出 0。
- 56 个非数据库测试脚本全部通过；最终构建后再次通过菜单布局、英文构建、构建一致性、冻结参数边界测试。
- 微信小游戏冒烟测试通过；新增完整关卡文案断言。数据库迁移未变，本次未重跑数据库测试。

## 残留风险与回滚

- 以上为内置浏览器模拟和小游戏测试环境，未代替 iPhone/微信真机验证；老旧、不支持 CSS 容器查询的 WebView 未验证。
- 极端长分数允许省略显示，完整数字保留在标题提示中；常规千万分在已测最窄尺寸下完整显示。
- 回滚本次提交并重新运行 `node 源码/工具/build_web.mjs`、`node 源码/工具/build_weapp.mjs`；勿只回滚生成的英文页。无数据迁移，无存档恢复步骤。
