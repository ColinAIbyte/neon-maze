# 2026-09-05 整合版发布说明

本版把手机操作与完整版双语优化、稳定本机存档及可选全球榜准备合并到同一游戏源码。

- 手机网页版开局显示左下角四向摇杆，保留滑动；电脑继续使用键盘。
- 结算成绩自动保存，昵称入口放在长战绩前面；多标签页不会因陈旧快照覆盖已获星星、最高分或解锁。
- 中文、英文由同源完整游戏构建，保留六关、练习、每日挑战及对手图鉴。
- 首次访问提供浏览器语言建议，手动语言选择优先；不请求第三方 IP 定位。
- 使用正式图标、分享图和独立域名元数据。
- 全球榜前端支持 Supabase 新版 publishable key 和旧 anon key，包含数据库初始化 SQL、只读开通检查及配置说明。

发布时云榜、流量统计和广告配置均为空或关闭；网站继续可直接游玩并保存本机成绩。
云榜将在专用服务建好、真实接口与权限验收通过后单独配置启用。

整合验收：44 项回归测试、六关地图校验、网页与微信构建、微信冒烟测试通过。
浏览器中英桌面/手机横竖屏共 8 组检查，以及 2 组模拟长结算检查通过。
发布前新增公开密钥兼容检查通过，并复验存档、英文同源、构建一致性和微信冒烟。

手机检查包含触屏模拟，仍需真实微信和移动网络试玩；云端 SQL 权限检查尚不等同于真实数据库验收。
开通计划见 [全球榜开通清单](CLOUD-LAUNCH-CHECKLIST.md)。
