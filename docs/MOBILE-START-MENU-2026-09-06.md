# 手机开始菜单横向漂移修复 · 2026-09-06

## 原因与范围

用户提供 iPhone 微信浏览器的英文页截图：外部棋盘不动，开始卡片内内容向左、向上偏移。基线 `cd71014713beb74d482786295d086a66c4b611f8` 的 `.start-card` 使用 `overflow:auto`，每日挑战四段英文全部不换行。内部溢出形成第二条滚动轴，不是图片自身的定位/动画问题。

仅修改共享源片段的开始菜单 CSS：横向禁止滚动、纵向按需滚动；每日挑战、个人纪录及辅助按钮自然换行；约束 flex 子项宽度且不挤塌内容。开始按钮不再继承结算页的底部偏移。横屏的紧凑规则也保留纵向滚动并从顶部排列，避免新增换行后标题或设置按钮被裁切。

不改 DOM、游戏脚本、关卡、玩法参数、敌人行为或全球榜协议。微信核心重建仅更新源码指纹，逻辑未变。

## 风险、上线与回滚

尺寸模拟和鼠标滚动不是 iOS WebKit/微信触摸验收；需用户在原手机重新打开英文页，斜向划菜单并滚到最下方确认。旧版浏览器对 overscroll-behavior 的支持可能不同，宽度约束与内容换行是主要防线。

按此前“优化好直接上线”的授权，本次仅发布该布局修复。上线后另以正式域名四条中英游戏/榜单路由及资产的文件摘要核对部署，并只读检查正式榜，不上传测试成绩。
