# AdSense 预留说明

当前版本没有接入真实广告：没有 `ca-pub-*`、广告单元 ID、`adsbygoogle` 或 Google
广告脚本。`config.js` 的 `showPlaceholders` 只用于查看预留版式，正式站应保持
`false`，直到广告方案完成政策与真机检查。

## 已预留的位置

- `adSlotRail`：160 × 600 宽屏桌面侧栏。只有视口至少 1800 × 720、当前未进行
  游戏且显式打开占位预览时才出现；手机、平板和游戏进行中始终隐藏。
- `notifyAdOpportunity('post_game')`：结算后的自然停顿挂点。它目前是空操作；若
  未来获准使用 AdSense H5 Games Ad Placement API，可从这里接入，而不是打断游戏。

## 真正上线前

1. 重新阅读最新 AdSense 与 H5 Games Ads 政策并确认账号具备相应产品资格。
2. 普通内容广告与游戏/开始/方向/重开等高频交互区保持安全距离，不把广告做成按钮。
3. 不做自动刷新、不以看广告换普通 AdSense 点击、不在连续游戏中突然弹出广告。
4. 加入清楚的“广告”标识、隐私政策，以及适用于访问地区的同意管理。
5. 只用测试/占位方式检查自己的页面，绝不点击自己的真实广告。
6. 上线前分别在手机、平板和桌面测试误触、焦点、滚动与页面加载性能。
