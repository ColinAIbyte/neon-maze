## 浏览器验收与复核入口

本次使用 Codex 浏览器真实排版，测试数据与存储隔离，所有云榜请求由本地内存数据库处理。
没有向正式榜提交测试成绩。截图和布局测量保存在本次任务的工具记录中。

- 中文：`http://127.0.0.1:8874/leaderboard/?count=3&me=3&recent=30`
- 英文：`http://127.0.0.1:8874/en/leaderboard/?count=3&me=3&recent=30`
- 云榜失败：增加 `mode=offline`。
- 本地存储异常：增加 `storage=corrupt` 或 `storage=blocked`。
- 写失败保留旧记录：`?recent=3&storage=quota&result=1`。
- 空状态：`?count=0`。

预览服务只监听 127.0.0.1，运行期间仅本机可访问；底部明确标注全部为测试数据。
没有这些预览参数的正式构建不会包含测试数据或测试钩子。

## 行为边界

最近记录使用独立的 `doudou.recent.v1`；每局含 runId、score、level、maxCombo、won、playedAt。
正式结算完成后立即记录，改名与云榜重试不重复记局。旧最高 8 条不伪造为最近战绩。
读取与记录复用现有 JSON 解析、损坏备份和分数校验，增加新字段严格检查。
存储事件会刷新本地展示；写前读取最新列表，已验证两个标签页交替结算。
这不是账号同步，也不承诺两个进程完全同时写 localStorage 的事务原子性。

游戏进行中的浏览器关闭或主动重开没有完整结算，不生成战绩。
最近列表滚动位置在云榜刷新和中英文切换时保持。
原历史查询接口保留以兼容旧客户端；当前大厅只请求 current 范围。
