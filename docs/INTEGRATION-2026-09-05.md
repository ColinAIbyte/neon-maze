## 复核并修复的问题

1. 两个标签页交错保存会覆盖新星星、最高分和解锁等级：写前合并，进度只增不减；
   普通保存沿用最新静音选择，只有显式开关才能覆盖，匿名 ID 优先沿用磁盘已有值。
2. 启动后的新解锁没有出现在菜单：菜单按需读取最新兼容存档；微信检查使用真实选关入口。
3. 云榜请求和响应体读取无超时：8 秒后结束等待并返回离线状态；非数组榜单响应安全回退。
4. 同局初次成绩提交和改名可能乱序：前端按局串行提交并固定每次请求的载荷。
5. 暂停后 Canvas 跳过重绘，导致网页摇杆及标题状态未更新：界面状态每帧独立同步，保留静态画布缓存。
6. 英文页新增全球榜文案和配置脚本路径：同源重建并检查全部翻译、相对路径与发布镜像。
