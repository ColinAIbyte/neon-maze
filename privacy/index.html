隐私政策

最后更新：2026-09-07

一句话：这个游戏几乎不收集你的信息。除了你主动上榜时填写的昵称和成绩，其余一切都留在你自己的浏览器里。

一、留在你浏览器里的（不会上传）

以下内容保存在你设备的浏览器本地存储中，我们看不到，也不会传到任何服务器：

  • 你的本机游戏成绩
  • 静音开关
  • 语言选择
  • 星星与解锁进度

清除浏览器的网站数据，这些会一并消失，无法找回。换一个浏览器或换一台设备也不会同步。

二、只有你主动确认才会上传的

只有当你在成绩结算页填写昵称并点击确认之后，这一局的以下内容会提交到全球排行榜：昵称、本局分数、到达关卡、最高连击、是否通关、提交时间。

同时会附带一个随机生成的匿名玩家 ID，用于成绩归属和基础校验。它不是账号，也不支持跨设备同步。

不确认就不上传。练习模式和每日挑战的成绩不会上传。

请注意：昵称和成绩是公开的，任何访问排行榜的人都能看到，并且会长期保留。我们不要求、也不建议你填写真实姓名或任何联系方式。我们不收集邮箱、手机号、生日、位置或任何身份信息。

三、我们没有做的事

  • 不使用追踪 Cookie
  • 不投放广告，也没有任何广告追踪代码
  • 不出售、不交换你的任何数据
  • 不做用户画像，不跨站追踪你
  • 不要求注册账号

网站启用了 Cloudflare Web Analytics，只统计每天有多少人打开了哪个页面。它不写 Cookie、不给你的浏览器打标识、也不跨站跟踪你，因此我们无法把两次访问认成同一个人。我们能看到的只有页面地址、访问次数、来源网站和大致的国家 / 设备类型这类汇总数字。

四、语言判断

网站默认显示英文。你可以随时用页面上的语言开关手动切换，你的选择会记在本地。这个判断完全在你的浏览器里完成，不会把任何信息发出去，也不会查询你的 IP 归属地。

五、涉及的第三方服务

服务用途会接触到什么
GitHub Pages网站托管和访问任何网站一样，服务器日志中会包含 IP 地址等常规访问信息
Supabase存储排行榜仅存储上面第二节列出的内容
Cloudflare Web Analytics统计页面被打开的次数页面地址、来源网站、以及从 IP 推断的大致国家与设备类型；不写 Cookie，不保留可识别到个人的记录

除此之外没有其他第三方会接触到你的数据。

六、关于儿童

这是一个休闲小游戏，我们知道有孩子在玩。

  • 我们不主动收集任何可以识别身份的信息
  • 上榜的昵称由玩家自己填写，我们建议不要使用真实姓名
  • 如果你是家长，发现孩子提交了不合适的昵称，可以用下面的邮箱联系我们删除

七、怎么删除自己的记录

想删掉你在排行榜上的记录，发邮件告诉我们昵称和大致的提交时间即可，我们会处理。

本地保存的内容不需要联系我们 —— 清除浏览器的网站数据就行。
