# 全球榜云服务开通验收

日期：2026-09-05。发布基线 `9e502bb`；本次配置只启用网页全球榜，统计与广告仍关闭。

## 项目与范围

- Supabase：`neon-maze-leaderboard`，项目 `nphdwmcyriinggjwwnfw`。
- 组织 Neon Maze，Free 套餐，实际区域东京 `ap-northeast-1`，PostgreSQL 17.6。
- 用户亲自完成登录和数据库密码设置。没有读取、保存或提交数据库密码、secret key、service_role 或登录 Cookie。
- 网页仅使用公开 publishable key。匿名正式挑战提交成绩；练习、每日挑战不上传。星级与解锁仍在本机，随机玩家 ID 不是跨设备账号。
- 微信小游戏的正式云榜接入不在本次开通范围；微信内打开网页与原生微信小游戏不是同一种客户端。

## 真实数据库与网络验收

1. 起始库公开表数为 0，排行榜表、视图与 RPC 均不存在。
2. `001` / `002` 试运行并回滚成功。首次匿名权限验收发现公开视图继承了 anon/authenticated 默认写权限；仅撤销 PUBLIC 不足以收回它们。
3. 新增 `003_public_view_readonly.sql`，显式撤销三类角色的视图权限后仅授予 SELECT。原有两份迁移保持历史原文。
4. 在同一回滚事务中依次执行三份迁移两遍，再运行 `transaction-tests.sql` 的 TEST BODY：**23 项通过**。实际切换到 anon 角色验证权限、合法写入、改名幂等、拒绝冒用、非法字段、计分与事件速率、每小时限频；32 条合成数据和所有试建对象随事务回滚。
5. 加空库保护后原子安装三份迁移，核对 RLS=true，底表 0 行。
6. 用正式 publishable key 执行 **58 次真实 HTTP 请求、15 项检查通过**：公开六字段、私有底表拒绝读取/写入、1 分测试成绩提交、重复改名、冒用与非法请求拒绝、CORS 头等。
7. 35 个并发新局请求得到 30 个接收、5 个限频；10 个相同局请求得到 1 个新记录、9 个重复结果。
8. 仅对预先保存的玩家/局 UUID 对、指定测试昵称和 1 分进行清理。清理前核对 32 行，清理后底表 **0 行**；没有真实玩家记录被删除。清理发生在网站云榜开放前。

当次请求中位耗时约 661 ms，P95 约 1,078 ms，最大约 2,582 ms；仅代表本机当时网络，不是全球或国内网络 SLA。

## 未验证与限制

- 浏览器尺寸模拟不等于真手机测试。仍需实际中国大陆移动网络、微信内置浏览器验证连通性和提交体验；没有声称已通过。
- HTTP 合成提交不是一次真人通关的生产 E2E。浏览器实测了读取；正常结算上传依靠同一前端模块与真实 HTTP 合同检查，需要后续真实试玩确认。
- 匿名 ID 和局内统计由客户端提供，可伪造；现有防刷不适用于奖金竞赛。免费服务可能闲置暂停或达到配额。
- NULL 客户端版本被底表 NOT NULL 拒绝，错误码 23502；不是应用 IF 的 22023。没有无效记录被接受。

完整本地证据保存在项目 `交付/2026-09-05/整合记录/`：`cloud-database-acceptance.json`、`cloud-api-live-01/plan.json`、`report.json`、`cleanup-result.json`、`cloud-release-tests.json`、`cloud-browser-layout.json`。这些包含合成验收 ID 的文件不放入公开网站。

需关闭云榜时清空 `config.js` 中的 Supabase URL/公开密钥并重建发布；不删库、不影响本机存档。
